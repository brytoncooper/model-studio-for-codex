## B19 — Brokered plugin data, jobs and events

**Written:** Plugin authority, scoped revision/quota storage, durable job repository, captured-context job broker, and schema/grant-aware event broker exist. Recorded slices include `b4a50c1` (storage), `b99a86f` (jobs), `2ace302` (events), `e621ee8` (storage broker), and `ef74e20` (job broker).

**Sources/tests:** [storage broker](../../../../python/src/model_deck/engine/plugin_data/service.py), [job broker](../../../../python/src/model_deck/engine/jobs/service.py), [event broker](../../../../python/src/model_deck/engine/plugin_events/broker.py), [job repository](../../../../python/src/model_deck/adapters/storage/sqlite_plugin_jobs.py); [storage broker tests](../../../../python/tests/engine/test_plugin_data_broker.py) include quota/CAS/cross-plugin denial; [event tests](../../../../python/tests/engine/test_plugin_events.py) include revocation before delivery/ack and retained content classification; [job broker tests](../../../../python/tests/engine/test_plugin_job_broker.py) include owner/captured-context/revocation checks; [repository tests](../../../../python/tests/engine/test_sqlite_plugin_jobs.py) include interruption and checkpoint retention.

**Integrated/verified boundary:** These are injected components. [bootstrap](../../../../python/src/model_deck/bootstrap.py) does not compose the brokers with a serving plugin supervisor. The [job broker guide](../../../../python/src/model_deck/engine/jobs/BROKER.md) explicitly excludes the runner, operator cancellation API and explicit resume. `jobs.get` schemas are not a serving dispatch implementation; no matching jobs handler was found in [dispatch](../../../../python/src/model_deck/engine/dispatch.py). Storage mutation/revocation exclusion depends on the supervisor sharing its guard.

**Missing acceptance:** End-to-end namespace/principal enforcement through supervised transport; public durable status/cancel/resume; actual worker-crash-to-interrupted orchestration; subscription revocation with real activation changes; plugin-to-plugin confused-deputy denial through dispatch; content grants across the installed lifecycle; and owned-data retention on deactivation. Component cases do not establish G6.

**Next ownable slice:** Compose trusted activation identity, authority and the three brokers behind supervisor broker dispatch, using temporary repositories and a deterministic child fixture. Explicitly exercise revocation while subscribed and crash interruption. Keep runner/resume API implementation as a separately assigned contract-bound slice.
